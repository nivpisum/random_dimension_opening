# RandomDimensionOpening 1.0.0

The original Forge 1.20.1 release chooses one of Minecraft's three vanilla
dimensions as the shared start of a world. The Overworld, Nether and End each
have a one-third chance. Later new players use the saved choice.

The Nether start uses a fixed height with a small netherrack platform. The End
start uses the original fixed coordinates, an end-stone platform and a chorus
flower. Its coordinate-based respawn handling follows the original 1.0.0 implementation.

Install this historical version on **both client and server** for multiplayer;
its original network channel requires the mod on both endpoints. Use Minecraft
1.20.1, Forge 47.x and Java 17. The JAR and embedded MIT declaration are unchanged.

For all loaded dimensions, native terrain-search starts and server-side-only
installation, choose **2.0.0** instead. The 2.0.0 code and new logo use CC0-1.0;
the unchanged 1.0.0 JAR retains its original MIT declaration.
